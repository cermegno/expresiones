Aplicaciones web para aprender expresiones en Español. Hay dos versiones:
- [simple](https://cermegno.github.io/expresiones/simple). Version sencilla ideal para estudiantes que no estan interesados en aprender jugando
- [tiki-taka](https://cermegno.github.io/expresiones/tikitaka). En esta version el estudiante ayuda a la seleccion de futbol a hacer pases y meter goles cuando adivina las expresiones con exito
